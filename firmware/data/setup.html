Layout editor

Layout editor: run on your PC (recommended until HA integration), e.g. cd tools/web-editor && python -m http.server 8081 — set device URL to http://omote.local.

Optional: host editor on-device (~118 KB flash) with pio run -e omote-rev4 -t uploadfs then open /editor/ (export backup first — uploadfs wipes layout).

While using the physical remote, avoid keeping large downloads open in the editor tab — it shares RAM with BLE/HA.
