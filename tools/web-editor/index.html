      HID identity
      
      
      
        Selects which Vendor_VVVV_Product_PPPP.kl keylayout Android
        loads, and therefore which KEYCODE_* values the TV reports
        for our buttons. Generic recovers the largest set of
        remote keys (NOTIFICATION / PROFILE_SWITCH / colour keys /
        Netflix-YouTube-Prime-Disney shortcuts). Changing the identity
        invalidates the existing bond — Omote forgets its side automatically;
        you must also forget the old bond on the TV and re-pair.
      
      
      
      
      
      
      
      
      
      HID test bench
      
      
      
        Send a raw HID code to the paired TV without using a Page action. Useful
        for discovering which codes the TV's keylayout actually accepts. Watch
        the result in your Android keymapper app or
        adb shell getevent -lq.
